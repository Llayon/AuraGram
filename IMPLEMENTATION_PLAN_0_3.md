# AuraGram 0.3.0: история, восстановление и скорость

Согласованный объём: локальный редактор, одна сохранённая сессия, без серверной части.
Мобильная проверка ограничена эмуляцией Chromium/WebKit, как согласовано ранее.

## 1. Модель настроек

- [x] Независимый снимок пресета, Beauty, ресниц, FX, коррекций, рамки и подписи.
- [x] Валидация идентификаторов и числовых диапазонов; исключены вкладки, сравнение и геометрия.
- [x] Загрузчик передаёт исходный Blob и имя без перекодирования.

## 2. Undo/Redo

- [x] До 50 действий без копий фотографии; новое изменение удаляет ветку Redo.
- [x] Группировка ввода ползунка; пресет, рамка, подпись, автостиль и сброс отменяются.
- [x] Кнопки, Ctrl/Cmd+Z и Ctrl/Cmd+Shift+Z; штатная отмена текста в подписи.
- [x] Синхронизация интерфейса; история очищается после успешной загрузки нового фото.

## 3. Одна локальная сессия

- [x] Сохранение включается пользователем; IndexedDB хранит исходные байты и настройки одной транзакцией.
- [x] Задержка 500 мс; «Сохранено» только после commit; после восстановления новая история и повторный анализ лица.
- [x] Выключение и удаление отменяют отложенные записи; текущая фотография остаётся открыта.
- [x] Обработка квоты, недоступного хранилища и повреждённой записи; новая загрузка приоритетнее восстановления.
- [x] Для совместимости с WebKit сохраняются байты ArrayBuffer, при чтении создаётся Blob.

## 4. Доступность инструментов

- [x] Понятные состояния загрузки модели, поиска, отсутствия лица и ошибки анализа.
- [x] Отдельные причины ограничений ресниц для каждого глаза; значения настроек сохраняются.
- [x] История и сохранение вынесены в переносимую строку для экранов 320/375 px.

## 5. Предпросмотр

- [x] Измерен исходный сценарий 3000×2400, предпросмотр 1080×864, Beauty=60, ресницы 50/30/40.
- [x] Кеш сглаженной цветокорректированной подложки и слоя с маской кожи.
- [x] Инвалидация при смене фото, источника, размеров или фильтра; слабая ссылка не удерживает старое фото.
- [x] Первичный замер на той же машине: медиана 163,8 → 121,4 мс (−25,9%); экспорт 1329,4 → 935,6 мс.

Замеры headless Chromium 156 / Windows, 16 логических процессоров, 5 прогретых
кадров, скрипт `node scripts/measure-editor.cjs`. Это локальный ориентир, не
гарантия для всех устройств. Один дополнительный буфер маски добавляет 471 552
байта RGBA в этом сценарии (максимум 384×384×4); оценка удерживаемых Canvas
46 650 172 → 47 121 724 байта. Это оценка размеров, не RSS и не память WASM/GPU.
Лимит L21 в байтах (<4 МиБ) и запрет роста буферов сохранены; лимит количества
увеличен с 8 до 9 для единственного нового слоя. Визуальные эталоны не меняются.
