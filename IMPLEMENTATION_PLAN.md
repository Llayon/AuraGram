## Журнал реализации
- План записан; начата реализация исправлений цвета, жизненного цикла фото и маски ресниц.
- Добавлен `src/exporting/prepareExport.mjs`: ожидание анализа и модуля, отмена при смене фото, ограничение времени. Подготовка подключена к экспорту; источник и настройки фиксируются, повторный запуск блокируется, буфер освобождается в finally. Гонки проверены четырьмя сценариями e2e-exporting.
- Добавлены шесть unit-проверок подготовки экспорта; общий набор 104 проверки проходит. `node --check src/app.js` проходит.
- Две новые браузерные проверки насыщенности и полосы ресниц проходят в Chromium с запретом внешних запросов.
- L24 теперь явно инициирует ретушь на локальном синтетическом изображении; эталоны не изменены.
- Установлен Tailwind 3.4.17 с фиксацией версии; `npm run build:css` создаёт локальный `src/utilities.css`. Генератор `scripts/vendor-ui.cjs` подготавливает локальные иконки и шрифты с лицензиями; ресурсы подключены и проверены в обоих движках.
- Первый прогон 82 сценариев выявил ошибку L17: тест обращался к скрытому ползунку после прямого изменения state. Теперь тест открывает инструмент кнопкой и проверяет реальные события клавиатуры в обоих направлениях независимости настроек.
- Затем локализованы шрифты и иконки, проверены задержанный SDK и его инициализация после запуска редактора. HTTPS блокируется на уровне контекста тестов, включая дополнительные вкладки.
- Проверены реальные повёрнутый и обрезанный портреты, внутренние уголки обоих глаз и масштабирование длины/толщины ресниц. Эталонные суммы G1b.1 не изменялись.
- Устранены переполнение шапки на 320/375px и выход окна экспорта за экран 320×568; добавлены проверки обоих движков.
- Состояние, рендерер, загрузчик, UI и экспорт вынесены в фабрики с явными зависимостями; `app.js` сократился с 1848 до 837 строк. После отдельных переносов проходили unit и целевые браузерные проверки.
- `npm ci` успешно выполнился с чистой установкой по lockfile; после него проходят сборка, упаковка, проверка MediaPipe и 104 unit-теста.
- Упакованный `dist/` проверен отдельным HTTP-сервером: загрузка модулей, настоящее распознавание, ретушь и PNG-экспорт проходят при запрете внешних запросов.
- На этапе локальной стабилизации YAML workflow разобран парсером; jobs: build, e2e, deploy. Удалённые проверки и публикация выполняются отдельным этапом выпуска.

## Выпуск 0.2.0

По следующему запросу пользователя подготовлен выпуск через GitHub PR:

- Проверки `build` и `e2e` запускаются на PR в `main`; устаревшие проверки того же PR отменяются.
- PR имеет только права чтения и не может публиковать сайт. Загрузка Pages-артефакта и деплой ограничены `main`; права Pages/OIDC выданы только заданию `deploy`.
- Публикация использует `dist/` после успешных проверок. Продакшен-деплои выполняются последовательно.
- Версия 0.2.0 записана в package/lockfile, HTML и runtime API; изменения перечислены в CHANGELOG.
- `npm run check:live` проверяет опубликованный сайт в Chromium и WebKit: версии, распознавание, ретушь/ресницы, сравнение и скачивание PNG при запрете внешних запросов.

Процедура выпуска и повторяемые команды описаны в разделе Deploy файла README.
